# Speed Test

Скрипт для замера скорости интернета. Прогревает соединение, затем
последовательно выполняет N HTTP-запросов к указанному URL через одну
`requests.Session` (keep-alive), замеряет время каждого, считает суммарный
объём скачанных данных и выводит среднюю скорость в **МБ/с**.

Тестовое задание для вакансии Python Developer (AD Robot).

[![CI](https://github.com/powerlord250191/speed-test.git/actions/workflows/ci.yml/badge.svg)](https://github.com/powerlord250191/speed-test/actions/workflows/ci.yml)

## Что делает

1. Принимает URL тяжёлого ресурса (например, большая картинка или тестовый файл).
2. Делает **холостой запрос для прогрева соединения** (DNS-резолв, TLS-handshake),
   чтобы они не попадали в статистику.
3. Выполняет `N` **последовательных** запросов через одну `requests.Session`
   (keep-alive, TCP-соединение переиспользуется).
4. Для каждого запроса замеряет:
   - время от начала запроса до полного чтения тела ответа (секунды);
   - количество реально скачанных байт.
5. Печатает прогресс по каждому запросу и итоговую сводку:
   - среднее время запроса;
   - общий объём скачанных данных;
   - среднюю скорость в **МБ/с** (мегабайтах в секунду).

## Требования

- Python 3.9+
- Зависимости из `requirements.txt`

## Установка

```bash
git clone https://github.com/powerlord250191/speed-test.git
cd speed-test


python -m venv .venv
source .venv/bin/activate      # Windows: .venv\Scripts\activate

pip install -r requirements.txt
```

## Запуск
Базовый сценарий — 10 запросов к большой картинке:

```bash
python speed_test.py https://disk.yandex.ru/i/8DnyUWfGggE6XA
```
На тестовом файле побольше (рекомендуется для честного замера):

```bash
python speed_test.py https://disk.yandex.ru/i/8DnyUWfGggE6XA
```
Параметры:

```bash
python speed_test.py <URL> [-n REQUESTS] [-t TIMEOUT] [--no-warmup]
```
Аргумент    По умолчанию   Описание
url               —        URL тяжёлого ресурса.
-n, --requests    10	   Количество последовательных запросов.
-t, --timeout	  30	   Таймаут одного запроса в секундах.
--no-warmup    	  выкл.    Отключить прогрев соединения (для отладки/сравнения).
-v, --verbose     выкл.    Подробный вывод (уровень DEBUG). 
-q, --quiet       выкл.    Тихий режим: только итоговая сводка. 
--log-file PATH   —        Дополнительно писать логи в файл. 

Пример с 5 запросами и таймаутом 15 секунд:

```bash
python speed_test.py https://disk.yandex.ru/i/8DnyUWfGggE6XA -n 5 -t 15
```
